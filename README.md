# Rental Room Management System

## 1. Project Overview

The Rental Room Management System is an individual web application developed for Internet Programming I.

The system helps tenants find available rooms for rent and allows landlords to manage room information and rental records.

## 2. User Roles

- **Tenant:** Browse available rooms, search by price, and submit rental requests.
- **Landlord:** Create, view, update, and delete room listings and manage rental requests.

## 3. Technology Stack

- Frontend: Vue 3, TypeScript, Vite
- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma
- Version Control: Git and GitHub

## 4. Main Features

- User registration and login
- Role-based access control
- Room listing management
- Room search and filtering
- Rental request management
- Database persistence
- Input validation and error handling
- Automated frontend and backend tests
